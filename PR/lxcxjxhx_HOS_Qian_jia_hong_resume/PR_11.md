新增独立目录 `RESUME-A4-QIANJIAHONG/`，把 A4 单页简历做成可复现的排版工程。

## 相对原版的差异

- **补充学校/专业**：原版只有「学历：本科在读」，现头部信息表新增 `上海建桥学院`、`计算机科学与技术（计科）· 本科在读 · 2028 届`。
- **A4 精确铺满**：`.page` 固定 `210mm × 297mm`，`overflow:hidden` 强制单页。实测填充率 **99.7%**、页脚距纸底 **0.94mm**、`overflowPx = -4`（仍有余量）。
- **版式升级**：去深色标题条，改为左竖线 + 章节标题 + 细延伸线；信息表改两列网格；开源 PR 列表四段定宽排布（7 行全部单行、无省略号截断）；页脚横线钉底。
- **证件照外置**：抽出为 `assets/photo.jpg`，不再内嵌 base64，HTML 从 ~2MB 降到 9.3KB。

## 导出与自检

`print.ps1` 用无头 Chrome 导出，强制 A4 / 无页眉页脚 / 100% 缩放。先删旧产物再导出，逐项校验写入时间、体积下限、页数与 MediaBox。

页数读取改用根 `Pages` 对象的 `/Count`：原来的 `/Type /Page[^s]` 正则计数在 Chrome 压缩对象字典时会假阴性——已用双页样张实测复现（该正则只数到 1 页），换用 `/Count` 后判定正确。

`out/*.mjs` 四个校验脚本（填充率与裁切、逐块 mm 定位、PR 行折行、截图预览），playwright 依赖自动回退：`PW` 环境变量 → 本地包 → 全局 `playwright-core`，不需要预先配置环境变量。

## 已记录的坑位

`PRINT.md` 里记了手动 Ctrl+P 的四坑（纸张可能默认 Letter、缩放不是 100%、边距必须选"无"、页眉页脚必须取消勾选），以及一个隐蔽的保存陷阱：`print.ps1` 含中文抛错文案，必须以 **UTF-8 with BOM** 保存，否则 Windows PowerShell 5.1 按 GBK 解析会直接 `Unexpected token` 报错。

## 不入库的内容

`out/*.pdf` 与 `out/*.png` 由脚本再生，已加入 `.gitignore`。目录体积从 2.16MB 降到 63KB。
