## 原因

`dco.yml` 的校验是行首锚定：

```bash
git log --format='%B' -1 "$sha" | grep -q '^Signed-off-by: '
```

而三个 workflow 的自动提交都是 `git commit -m`，从不带 `-s`：

```yaml
git commit -m "Auto-build resume: Chinese + English (HTML/DOCX/PDF)"
```

所以 bot 每推一次就产生一条在 DCO 看来不合格的提交。

## 修复

三处改为 `git commit -s`，bot 以自身身份签名：

```
Signed-off-by: github-actions[bot] <github-actions[bot]@users.noreply.github.com>
```
