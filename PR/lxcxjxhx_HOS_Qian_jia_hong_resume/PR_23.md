## 关于「让 HR 大概率接受简历」

说一句实话：**自我介绍不是简历的胜负手**。HR 初筛平均 6–10 秒，实际看的是「学校/学历 → 实习公司 → 项目关键词」这条扫描路径，自我介绍通常扫不到。

真正在起作用的是前面几项：绿盟科技的实习抬头、5 项软著带流水号、开源 PR 带大厂仓库名和 star 数、以及「Claude Code / Codex / DSH / Pi」这些技术面试官认得的词。这些都已经在简历里了。
