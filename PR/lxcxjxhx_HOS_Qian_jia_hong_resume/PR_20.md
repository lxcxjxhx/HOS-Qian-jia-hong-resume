## 修一处我自己引入的缓存缺陷

上一版 PR 的指纹**只哈希 `resume.html`**。这意味着我改了 `TERM_FIXES` 后源文件没变，缓存会判定「未变更」直接复用旧产物——**新规则永远不生效**。

现在改成复合指纹：

```python
rules = RULES_VERSION + GLOSSARY + TERM_FIXES + FULLWIDTH
sha256(html + rules)
```

规则一改自动失效重译。已实测：改规则后指纹从 `0dbd26e4` 变为 `ce7651f8`，缓存正确失效并重译 75/75 段。
