## PR 描述

## 背景与动机

对 8 篇 arxiv 论文实测后发现的真实问题（本次 PR 的直接证据）：

1. **PDF 直提丢内容/拆碎片**：`pdf-extract.py` v1 只用 `page.get_text()`。
   - 公式被拆成碎片：`k ∈`、`j ∈ES`、下标丢失（`vso` 变 `vso`）
   - 表格提取后列错乱 → **会直接污染评审结论**（如某篇报告中"表格多处 Loc>Det 违反指标单调性"实际是表格列错乱造成的误判）
   - 扫描/图密集页静默丢内容：T2L-Agent 共 41 页，**第 21-41 页全部为图表页**，v1 静默缺一半内容却无任何提示
2. **输出只有 MD**：`render.ts` 只出 Markdown，格式在部分场景变形；用户需要美观可浏览的 web 页面 / PDF。
3. **PDF 转换消耗 token**：若让宿主 LLM 自行把 MD 转成 PDF，昂贵且不可控——应交给 script 完成。
