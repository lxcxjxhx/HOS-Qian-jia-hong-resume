## 🤖 S-16-HOS-CAD-Builder

MCP Agent Skill for AI-driven CAD model generation, modification, validation, and export.

### ✨ Tools

| Tool | Description |
|------|-------------|
| `cad_generate` | Generate 3D CAD models from natural language descriptions |
| `cad_modify` | Incrementally modify existing models |
| `cad_export` | Export to STEP / STL / 3MF / GLB / DXF |
| `cad_validate` | Check printability & wall thickness |
| `cad_parts_find` | Search standard parts library (7 built-in parts) |
| `cad_robot_urdf` | Generate URDF / SRDF robot descriptions (2 templates) |

### 🏗️ Architecture

4-stage pipeline:

```
NL Prompt → Spec Planner → Geo Architect → Code Generator → Python Bridge → build123d → CAD Files
```

- **TypeScript** + `@modelcontextprotocol/sdk` (MCP Server)
- **Python** + `build123d` (CAD execution engine)
