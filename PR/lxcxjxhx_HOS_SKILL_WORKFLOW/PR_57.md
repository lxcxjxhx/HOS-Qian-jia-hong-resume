## Summary

New entertainment-series skill **X-00-HOS-Chara-Sequence**: a scene-config driven ComfyUI framework that generates smooth frame-by-frame character progression portraits as PNG sequences, ready for game engines.

> Prefix `X` = eXtra/Entertainment — independent numbering (X-00, X-01, ...), sorts last in the index (lowest priority), separate from professional engineering S-series.

### What's included
- `SKILL.md` — full playbook: architecture, scene config schema, key parameters, known pitfalls, verification flow
- `scripts/gen_stage_prompts.py` — scene config → N-frame progressive prompts with uniqueness auto-check
- `scripts/gen_workflow_t2i.py` — expanded T2I workflow generator (stable on ComfyUI 0.30.2, avoids Easy-Use loop race bug)
- `scenes/` — 3 example scenes: chara_growth / dragon_evolution / magical_girl_transform

### Key design points
- Pure T2I (no img2img/base image) — latent constraints suppress prompt-driven changes
- Fixed seed + fixed style segment for identity consistency
- Per-frame unique SaveImage prefix to avoid ComfyUI 0.30 concurrent counter overwrites
- Verified: 3 scenes × 100 frames, all prompts unique (100/100)
