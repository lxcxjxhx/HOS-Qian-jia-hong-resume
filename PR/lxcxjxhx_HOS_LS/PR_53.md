## Summary

Add fixture-based compatibility tests for the static adapters:

- `tests/fixtures/ecatsl/static/` — 12 JSON fixtures:
  - InputTracer: complete path, no-path, incomplete, sanitized/blocking metadata, declared/observed parameter mismatch, and adapter exception shape.
  - CodeQL/SARIF: complete ordered code flow, plain SARIF hit, missing source provenance, empty propagation, blocking sanitizer evidence, and malformed output.
- `tests/unit/ecatsl/test_static_adapters.py` — 13 pytest cases asserting:
  - complete path → confirmatory `PathEvidence`; all incomplete/unsupported/sanitized/malformed shapes stay unconfirmed with retained non-confirmatory `ValidationResult`;
  - adapters delegate to the real `InputTracer`/`SastPrefilter` APIs (delegation bound at construction) and never reimplement tracing;
  - raw-output identity, failure reason, and observed location identities are preserved;
  - catalog/discovery/RAG/LLM hints are never upgraded into path elements.
