## PR 描述

## 问题

NVD 数据库文件缺失时，scan 触发 `_check_data_preload_status` 的 `click.confirm`（默认 True）→ **自动执行 `DataPreloader.download_all` 全量下载 → 网络挂起/卡死**，扫描无法继续。

## 修复（`src/cli/main.py`，+10/-19）

db 缺失或文件异常（<1MB）时**直接降级内置 DB**：
- 输出警告 + 提示手动运行 `hos-ls data-preload run`
- 不交互、不自动下载（消除挂起点）

```

修复前: 无限挂起
修复后: 快速完成（内置 DB 降级，3 findings，报告正常生成）✓
```

> 该 bug 同时阻断了 NVD 影响对照实验（此前物理禁用 db 会挂起）。
