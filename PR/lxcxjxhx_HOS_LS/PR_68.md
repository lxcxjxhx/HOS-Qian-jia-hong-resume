## PR 描述

## 问题

HOS-LS 之前没有 issue 表单。报漏报/误报的人只会写「它没扫出来」—— 没有代码片段、没有引擎线索、没有版本，排查只能靠来回问。

## 两份表单

**bug**：先按「漏报 / 误报 / 崩溃」把问题说清楚，再选**哪个环节**出的问题：

- 静态规则（rule）
- LLM 分析（ai / pure_ai）
- 库匹配（library）
- 网络检索（web）
- CLI / 报告输出

强制给最小复现与 `--debug` 输出；开头把安全问题挡到 `SECURITY.md`。

**feature**：按「规则 / LLM 分析 / 报告 / CLI / 性能」分区，并要求确认这不是规则表的既定取舍。

## 为什么不是通用模板

分区就是项目的真实分层 —— 这个仓的扫描结果是四个引擎拼起来的（rule / ai / library / web），
报「没扫出来」时最关键的第一个信息就是**哪个引擎该扫出来**。通用模板收不到这个。
