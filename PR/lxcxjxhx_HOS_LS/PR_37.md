## 修复HOS-LS API配置问题

### 问题描述
HOS-LS的7-Agent系统无法使用自定义API端点（如`https://token-plan-cn.xiaomimimo.com/v1`），导致401/404认证错误。

### 根本原因
1. **CLI硬编码模型名**：`src/cli/main.py`在`--pure-ai`模式下强制将模型设为`deepseek-v4-flash`，覆盖配置文件设置
2. **配置加载问题**：`pure_ai_analyzer.py`使用`get_config()`获取全局配置，而不是CLI传入的配置

### 修复内容

#### 1. CLI配置修复 (`src/cli/main.py`)
```python
# 修复前（硬编码）
config.ai.modules["pure_ai"].model = "deepseek-v4-flash"

# 修复后（使用配置文件）
if not config.ai.modules["pure_ai"].model:
    config.ai.modules["pure_ai"].model = config.ai.model
```

#### 2. 配置加载修复 (`src/ai/pure_ai_analyzer.py`)
```python
# 修复前（使用全局配置）
temp_config = get_config()

# 修复后（使用传入的配置）
temp_config = self.config
```
