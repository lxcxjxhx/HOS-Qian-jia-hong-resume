## PR 描述

Method: extracted every `t('<ns>:<key>')` call that carries an explicit namespace from `projects/app/src` and `packages/**` (**2910 keys**), then compared them against the `zh-CN` namespace JSONs. Seven keys are undefined everywhere.

### 1. One is a typo — fixed in code

`AccountCancellationConfirmModal.tsx` calls `t('common:cancel', '取消')`, but the key is `common:Cancel` (present in all four locales as 取消 / Cancel / 取消 / 취소). Changed to `t('common:Cancel')`; the duplicate key is not added.

### 2. Six are genuinely missing — added to all four locales

| key | where it renders | zh-CN | en |
|---|---|---|---|
| `publish:ip_whitelist` | share-link modal, IP 白名单 label | IP 白名单 | IP whitelist |
| `chat:sandbox_connection_closed` | sandbox editor, socket close reason | 沙箱连接已断开 | Sandbox connection closed |
| `chat:sandbox_invalid_file_name` | sandbox editor, three toast descriptions | 文件名不合法 | Invalid file name |
| `skill:generating` | skill list, generating state | 生成中 | Generating |
| `file:empty_file` | dataset search test, empty result title | 文件为空 | Empty file |
| `common:Version` | plugin batch-update drawer fallback | 版本 | Version |

`zh-Hant` and `ko-KR` are filled in the same pass.

### Why it matters

Each of these currently renders either the raw key (`chat:sandbox_invalid_file_name`) or, in the `common:cancel` case, a hard-coded Chinese fallback that English and Korean users see as 取消.
