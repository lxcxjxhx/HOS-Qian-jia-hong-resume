## PR 描述

Three `agentHint` values in `automationMeta.ts` reach the UI as raw i18n keys instead of text.

`workflowBuilderTemplateBundle()` translates every hint unconditionally:

```ts
{ ...meta, agentHint: meta.agentHint ? translate(meta.agentHint) : undefined }
```

so a hint whose key does not exist is displayed verbatim — `workflow:cli.input.dataset_quotes` and `workflow:cli.input.custom_feedback` are shown to the user as those strings. Neither key exists in any of the four locales:

```text
$ for l in en zh-CN zh-Hant ko-KR; do grep -c 'cli.input.custom_feedback\|cli.input.dataset_quotes' \
    packages/web/i18n/$l/workflow.json; done
0
0
0
0
```

The third one is a different failure in the same line: the key is glued to the guidance text it was meant to introduce.

```ts
        agentHint:
          'workflow:cli.input.text_editor. This is a literal text field. Embed references using {{$nodeId.outputKey$}}; …',
```

`cli.input.text_editor` *does* exist, but no lookup can match the string with a sentence appended, so the tooltip shows the key plus the whole English paragraph, in every locale, including the two Chinese ones and Korean.

## What changed

- `cli.input.dataset_quotes` and `cli.input.custom_feedback` added to all four locales, grouped with their `cli.input.*` siblings.
- The text-editor hint now references the bare key, and the guidance it used to carry lives in the `cli.input.text_editor` value in each locale, so it is translated rather than printed raw.

The three keys, `en` / `zh-CN`:

```json
"cli.input.custom_feedback": "Feedback text to append to the current conversation record",
"cli.input.dataset_quotes": "Dataset references supplied by an upstream node",
"cli.input.text_editor": "Static text or text assembled from upstream variables. This is a literal text field. Embed references using {{$nodeId.outputKey$}}; global variables use {{$VARIABLE_NODE_ID.variableKey$}}. Do not generate bare {{variableKey}} or {{nodeId.outputKey}} placeholders."
```

```json
"cli.input.custom_feedback": "要追加到当前对话记录的反馈内容",
"cli.input.dataset_quotes": "由上游节点提供的知识库引用",
"cli.input.text_editor": "静态文本或由上游变量拼接的文本。这是纯文本输入框。用 {{$nodeId.outputKey$}} 引用上游输出，全局变量用 {{$VARIABLE_NODE_ID.variableKey$}} 引用。不要生成裸的 {{variableKey}} 或 {{nodeId.outputKey}} 占位符。"
```

`zh-Hant` and `ko-KR` carry the same three entries; the template placeholders are left untouched so the reference syntax examples stay valid.
