## PR 描述

## What

Three docstrings cite `skillevaluator.plugin_components`. That module was never created — the inventory lives in `skillevaluator.plugin_inventory`.

The timeline says why: the citations landed in #250 (`2026-10-29`), and #257 (`2026-10-30`) composed the inventory under the `plugin_inventory` name. The references were written one day before the implementation picked a different filename, and nothing went back to update them.

Result today: a reader following the pointer finds no such module, and `grep plugin_components` in the package returns only those three docstrings.

## Scope

Two of the three are `:mod:` roles, where the intended target is unambiguous:

| File | Before | After |
|---|---|---|
| `plugin_mcp.py:13` | `:mod:\`skillevaluator.plugin_components\`` | `:mod:\`skillevaluator.plugin_inventory\`` |
| `plugin_paths.py:16` | 同上 | 同上 |

**Deliberately not included**: `plugin_manifest.py:280` cites `:func:\`~skillevaluator.plugin_components.build_plugin_inventory\``. That function does not exist either, and the sentence describes it as taking an `additional` argument — while the inventory module's entry point is

```python
def plugin_inventory_for_root(
    path: Path, *, allowed_private_hosts: Iterable[str] = (), hook_allowed_urls: Iterable[str] = ()
) -> PluginInventory | None:
```

No `additional`, different parameters, different return. Replacing the reference there means deciding what the paragraph was describing, which is a guess I would rather not make inside a docs fix. Happy to take it separately.

## How it was found

Resolved Sphinx cross-reference roles (`:class:` / `:func:` / `:mod:` …) in docstrings against the symbols the package actually defines, then checked dotted targets on the filesystem.

The first version of that check only compared symbol names, and in another repository it reported `harbor.upload.db_client` as missing — a module that exists at `src/harbor/upload/db_client.py`. Adding a filesystem resolution step for dotted targets removed that false-positive class; what is left here are references whose module genuinely is not present.
