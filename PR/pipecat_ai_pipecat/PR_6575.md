## PR 描述

`WhisperSTTServiceMLX.run_stt` drops hallucinated segments with

```python
if segment.get("compression_ratio", None) == 0.5555555555555556:
```

`compression_ratio` measures how well the segment text compresses, so it is never equal to a fixed value: the check under the `# Drop likely hallucinations` comment never matches, and a segment the model produced by looping reaches `TranscriptionFrame` — and then TTS — unchanged.

Compare against the threshold Whisper's own decoding uses for repetitive output (`compression_ratio_threshold = 2.4`), and default a missing field to `0.0` so a backend result without that key is kept.

The tests replace `mlx_whisper` in `sys.modules` (the service imports it lazily inside `run_stt`), so they run on every platform and need no Apple Silicon. Before the change `test_repetitive_segment_is_dropped` fails with both segments in the transcript; after it, both tests pass.

Verified locally: `pytest tests/test_whisper_mlx_hallucination.py tests/test_whisper_stt_transcribe.py tests/test_whisper_stt_language.py` → 14 passed; `ruff check` and `ruff format --check` clean.
