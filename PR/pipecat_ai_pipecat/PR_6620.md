## What

Two examples in `expand_numbers` show output the transform does not produce.

`num2words` writes hyphenated compounds, a thousands separator and an "and":

```python
>>> num2words(42, lang="en")
'forty-two'
>>> num2words(1234, lang="en")
'one thousand, two hundred and thirty-four'
```

The docstring's prose example said `"42"` → `"forty two"`, and its code example claimed

```
"Room forty two has one thousand two hundred thirty four seats and opens in 2 0 2 6"
```

for `"Room 42 has 1234 seats and opens in 2026"`, while the transform returns

```
"Room forty-two has one thousand, two hundred and thirty-four seats and opens in 2 0 2 6"
```

Both examples now match the output. Anyone who checked the transform against its own docstring, or wrote a test from it, saw a failure that isn't one.
