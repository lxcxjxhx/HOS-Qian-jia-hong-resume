## What

Two amounts came out of `expand_currency` in a shape a voice reads wrongly.

| input | before | after |
|---|---|---|
| `$2.50 million` | two point five **zero** million dollars | two point five million dollars |
| `$1.0 million` | one point **zero** million dollars | one million dollars |
| `$1.50 billion` | one point five **zero** billion dollars | one point five billion dollars |
| `US$5` | **USfive dollars** | US five dollars |
| `CAD$10` | **CADten dollars** | CAD ten dollars |

The scaled branch spells the fraction digit by digit, so a zero written for cents precision became a spoken word; the substitution replaces only the symbol, so a currency code written directly against it ended up glued to the spoken amount.

What stays as it was: `$2.5 billion` still reads "two point five billion dollars", a zero inside the fraction is still read (`$2.05 million` → "two point zero five million dollars"), and a symbol with no code before it expands unchanged (`pay $5` → "pay five dollars").
