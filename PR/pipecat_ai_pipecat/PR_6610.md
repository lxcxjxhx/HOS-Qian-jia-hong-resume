## PR 描述

## What

`scripts/deprecations/scan.py` keys its exclusion set by a repository-relative path, but builds that key from `str(Path)`:

```python
DEFAULT_EXCLUDE = frozenset({"pipecat/utils/deprecation.py"})
...
relpath = str(py_file.relative_to(src_root.parent))
if relpath in exclude:
    continue
```

On Windows `str(Path)` renders `pipecat\utils\deprecation.py`, so the comparison never matches and `DEFAULT_EXCLUDE` silently does nothing — the convention's own home module (`pipecat/utils/deprecation.py`, which documents the `.. deprecated::` grammar and implements `warn_deprecated()`) gets scanned and reported as a violation of the rules it implements.

Effect on Windows, on a clean checkout:

```
$ pytest tests/test_deprecation_markers.py -q
4 failed, 32 passed

FAILED test_warn_messages_follow_template
FAILED test_directives_state_removal_version
FAILED test_deprecation_warnings_use_the_helper
FAILED test_deprecations_registry_is_up_to_date

E   AssertionError: These `.. deprecated::` directives don't state a removal version — add `Will be removed in X.Y.Z.`:
E       pipecat\utils\deprecation.py (<module>): 'Use :class:`~pipecat.pipeline.worker.PipelineWorker` instead. ...'
E   AssertionError: These deprecation warnings call warnings.warn() directly; use pipecat.utils.deprecation.warn_deprecated():
E       pipecat\utils\deprecation.py:125: call warn_deprecated() instead of warnings.warn()
```

and the registry generator refuses to run at all:

```
$ python scripts/deprecations/generate.py
ValueError: Refusing to build the deprecation registry — fix these markers first:
  check_directive_removal_versions: pipecat\utils\deprecation.py (<module>) ...
  check_warn_helper: pipecat\utils\deprecation.py:125 ...
```

The `warnings.warn()` it "should not call" is the one inside `warn_deprecated()` — the helper has to call it; and the `<module>` directive it "should state a version for" is the docstring example of the grammar.

## Change

```diff
-        relpath = str(py_file.relative_to(src_root.parent))
+        relpath = py_file.relative_to(src_root.parent).as_posix()
         if relpath in exclude:
```

`DEFAULT_EXCLUDE` is a POSIX-keyed set (it is also what the docs and `deprecations.json` use for `path`), so the scan key should be POSIX on every platform. `as_posix()` is a no-op on Linux/macOS, where the current code already works.
