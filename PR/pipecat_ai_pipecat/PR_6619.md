## PR 描述

## What

A percentage written with a thousand separator came out of `expand_percentages` in two pieces.

| input | before | after |
|---|---|---|
| `1,500%` | `1,five hundred percent` | one thousand, five hundred percent |
| `12,500%` | `12,five hundred percent` | twelve thousand, five hundred percent |
| `1,000,000%` | `1,five hundred percent` | one million percent |

The regex matched the digits after the separator on their own, so the separator was left standing in front of the spoken amount and the number read as `500`.

Through the default `VoiceFormatter`, which applies percentages before units:

```
'Sales grew 1,500% last year'  ->  'Sales grew 1,five hundred percent last year'   (before)
                               ->  'Sales grew one thousand, five hundred percent last year'  (after)
```

The separator is part of the matched number now, as it already is in `expand_currency` and `expand_numbers`. Amounts without a separator read exactly as before (`50%`, `3.5%`, `0.25 %`).
