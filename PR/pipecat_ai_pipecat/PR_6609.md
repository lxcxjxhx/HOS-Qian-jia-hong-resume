## PR 描述

## What

Without the `livekit` extra installed, `tests/test_livekit_transport.py` does not skip — it **fails at collection**:

```
$ pytest tests/test_livekit_transport.py -q
ERROR tests/test_livekit_transport.py - NameError: name 'LiveKitTransportClient' is not defined
16 errors
```

The module guards its imports:

```python
try:
    from livekit import rtc
    from pipecat.transports.livekit.transport import (..., LiveKitTransportClient, ...)
    LIVEKIT_AVAILABLE = True
except ImportError:
    LIVEKIT_AVAILABLE = False


@unittest.skipUnless(LIVEKIT_AVAILABLE, "livekit package not installed")
class TestLiveKitVideoStreamMemoryLeak(unittest.IsolatedAsyncioTestCase):
    def _create_client(self, video_in_enabled: bool) -> LiveKitTransportClient:
```

but `@unittest.skipUnless` only skips *running* the tests: the class body is still executed when the module is imported, and its method annotations are evaluated eagerly (the module has no `from __future__ import annotations`). With the extra absent, `LiveKitTransportClient` is undefined and the annotation raises.

Effect: anyone running the suite without `pipecat-ai[livekit]` gets 16 collection errors instead of 74 skips, and a collection error makes the whole file un-runnable rather than "not applicable here".
