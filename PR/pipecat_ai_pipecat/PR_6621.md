## PR 描述

## What

`ActionManager` decided how to call a handler by testing the handler itself:

```python
if inspect.iscoroutinefunction(handler):
    await handler(action, self._flow_manager)
else:
    handler(action, self._flow_manager)
```

A handler that is an object with an async `__call__`, or a sync wrapper that returns a coroutine, fails that test. It was called, its coroutine was dropped, and the action was logged as executed without ever running — the deprecation-free shape of the bug #6617 fixes for `BaseObject`'s event handlers, in the same dispatch form:

```python
result = handler(action, self._flow_manager)
if inspect.isawaitable(result):
    await result
```

Both dispatch sites take the change: the two-parameter branch and the deprecated single-parameter one.

## Evidence

With `tests/test_flows_actions.py` extended by the two handler shapes:

```

after:   16 passed
```

The two new tests register a handler that is a callable instance, and one that is a sync wrapper returning the coroutine, and assert the action body ran. Neither runs without the change.
