### Motivation & Context

`agent_framework/orchestrations/__init__.py` is a lazy re-export namespace: it serves the names in its `_IMPORTS` list through `__getattr__`, and `__init__.pyi` declares the same surface to type checkers. The two lists disagree — six names exist at runtime but are absent from the stub:

```
BaseGroupChatOrchestrator
GroupChatResponseReceivedEvent
OrchestrationState
TerminationCondition
clean_conversation_for_handoff
create_completion_message
```

Consequence: `from agent_framework.orchestrations import BaseGroupChatOrchestrator` works when the extra is installed, but a type checker resolves the module through the `.pyi` and reports an unknown import symbol — so users who follow the orchestrations samples get a red squiggle on correct code, and anyone reading the stub concludes the API is smaller than it is.
