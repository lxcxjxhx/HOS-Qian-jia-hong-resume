## PR 描述

## 问题

单资产的 `report.md` 有覆盖一节：

```
覆盖：2/2 面 · 适用 4 对 · 执行 4 · 缺口 1（critical 0 / warn 1） · 完整：否
```

平台汇总**只读 findings.json**，不读 `coverage.json`：

```
- 结论：已验证 2 / 总项 4      ← 分母整个消失
```

D3 的口径正是“覆盖率必须带分母”。run 有账本，platform 只搬了结论——
同一份数据两个出口，只有一个是完整的。

## 改法

- 逐资产读 `coverage.json`（`rc != 0` 仍不读，沿用 B159 的口径）
- 表加两列：`覆盖（面）`、`缺口`；未产出资产两列同样标 `—`
- 明细每资产写一行覆盖 + 完整性 caveat
- 报告头加 `覆盖合计：已判定 X/Y 面 · 缺口 Z（critical A / warn B）`
