## 问题有多严重

```python
index_of[oracle_id] = doc     # 后一个面覆盖前一个
```

多面执行后每条 finding 都指向 `index_of[oracle]`，即**最后一个面**的 capsule。

**「面 A 的发现」引用「面 B 的证据」**——replay 会验到错的那一面。一个自称可复核的工具，
把证据指到别处，这比少报一条严重得多。

## 改法

- 索引键：`(oracle_id, face_ref)`
- `case_id`: `run-{oracle}-{面尾}`
- 封印后按 `cap.route.ref` 回填（链哈希会改字节，面归属不变）

## 踩坑（被自己的断言救了）

回填第一版写成 `doc.route_ref`——`CapsuleDoc` 上没有这个字段（真实路径 `route.ref`），
全部落到空串键。报告侧拿不到 capsule，`assert_renderable` **直接拒绝渲染**：

```
RenderError: F-csp_absent-38dcb568: VERIFIED 无 capsule，拒绝渲染
```

这正是那层断言该干的事：**证据缺了就不许出报告**，而不是产出一份没有证据的报告。
