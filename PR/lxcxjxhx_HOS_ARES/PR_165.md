## 问题

`Loop._dispatch` 里：

```python
self.verdicts[oracle_id] = verdict      # 直接覆盖
```

hunt 一个 oracle 会跑多条面（游标推进）。于是：

```
A 面 VERIFIED → B 面 REFUTED
  verdicts[oracle] = REFUTED
  hunt 的 findings（只收 VERIFIED）= 空        ← 这条洞从汇总里消失
  控制台 faces_run（逐面） = 1 条 reported     ← 同一份数据，另一个出口
```

少报的那一头，正好是“真发现了”的那条。

## 改法

**只有 VERIFIED 是粘的**：任何一条面成立，这个 oracle 就成立；其余仍按后一条面记。

```python
if self.verdicts.get(oracle_id) != Verdict.VERIFIED.value or (
    verdict == Verdict.VERIFIED.value
):
    self.verdicts[oracle_id] = verdict
```

不把 REFUTED 也做成粘的：没成立的结论没有方向性，按最后一条面记即可——
反过来粘会让“先否后成立”也读不出来。
