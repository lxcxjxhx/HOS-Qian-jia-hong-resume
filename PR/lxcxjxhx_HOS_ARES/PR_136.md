## 这一条的价值一半在判据，一半在“敢说不适用”

http 目标上问“缺不缺 HSTS”没有意义——浏览器不认。如果顺手判否，每个 http 站点都会
被标成“缺 HSTS”，那是**假阳性**；如果跳过不记，账本又会以为“这条面没被判”。
所以它返回 `INCONCLUSIVE(not_https)` 并把原因写进断言：

```json
{"kind": "not_applicable", "observed": {"scheme": "http"},
 "fingerprint": {"applicable": false}}
```

## 为什么 scheme 放 Trace

每条 oracle 自己判断“我是不是 https”，就会各写一遍——B113（参数三处各抄）、
B123（档名抄成清单）都是这么分叉的。传输层知道协议，就由它报；`Trace` 只带协议名，
**不带 host/port**，地址仍然只在 `binding` 里。
