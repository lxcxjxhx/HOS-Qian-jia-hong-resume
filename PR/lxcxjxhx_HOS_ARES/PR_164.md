## 问题

B154 之后 hunt 会封 capsule，真跑一次确实落了 2 份、链也过。但控制台还说“没有”：

```python
# web/loader.py
capsule_id=None,   # hunt 不封 capsule：不编
```

更麻烦的是如果按 oracle 建索引：`hunt.json` 原来的 `capsule_ids` 是
`{oracle: id}`，同一 oracle 两个面时，两条 finding 都会显示**后一份**——
“面 A 的发现引用面 B 的证据”，B148 在报告侧修过的那条，在控制台又出现一次。

## 改法

- `hunt.json` 记录**逐面**证据：`evidence: [{oracle, route_ref, capsule_id}]`
- `web/loader.py` 按 `(oracle, route_ref)` 建索引；没有证据才是 `None`
- 控制台的 `capsule` / `capsule_present` 两段随之为真（有就显示，没有就是没有）
