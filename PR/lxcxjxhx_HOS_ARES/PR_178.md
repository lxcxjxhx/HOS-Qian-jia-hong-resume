## PR 描述

## 问题

真跑 `_do_sh`：

```
sh python -V                 → SyntaxError: invalid syntax
sh python -c "print(6*7)"    → exit=0 :: （空输出）
```

两处病串起来：

1. `_do_sh` 按首词猜解释器：首词含 `python` 就把**整行**塞进 `python -c`，
   于是 `python -V` 变成 `python -c "python -V"`；
2. 即使判定改对：Windows 上 argv 形式调用 `cmd` 会经过 `list2cmdline`，
   内层引号被转义成 cmd 不认的形式——`python -c "…"` **exit=0 且空输出**。
   agent 账本记 `ok`，人以为代码执行了。

最坏的不是报错，是**静默成功**。agent 工作台的价值全在“执行的每一步都是真的”。

## 改法

- `cmd_agent._do_sh`：`sh` 就是“跑一条命令”，解释器由系统 shell 决定，不按首词猜
- `workbench/executor.py`：Windows 上把整行**以字符串**交给 `cmd`（shell 形式）；
  POSIX 仍是 `sh -lc <script>`（本来就按字符串传）。超时杀进程组、输出封顶、
  env 白名单三条纪律不变
