## 为什么 replay 的顺序不能换（06 §5.1.1）

完整性 → 授权 → **路由** → 重发 → 重判。把"重发"提到"路由"前，端点下线会 404 →
FAILED → 报告写成"已修复"。这正是外面那些扫描器被诟病的那一类误报，所以顺序被三条测试钉住。
