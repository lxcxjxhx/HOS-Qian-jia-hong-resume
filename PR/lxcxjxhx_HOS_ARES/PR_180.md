## PR 描述

## 问题

`Workbench` 从 B37 起就有 `glob`（排序、封顶、链接逃逸跳过）和 `grep`（返回行号与原文），
但 `veripen agent` 的指令白名单只有 `read / write / edit / sh`——

想找文件只能 `sh dir /s`，想搜内容只能 `sh findstr`。用户被迫用 shell 做工作台
自己会做的事，等于把边界检查（工作根、匹配上限）也绕开了。

## 改法

- `COMMANDS` 增加 `glob` / `grep`
- `_do_glob`：`N 个文件 :: a、b、c…`（排序、走同一套 `check_relative`）
- `_do_grep`：`N 处 :: 路径:行号 原文`；顺带剥掉 Windows BOM
  （实测：带 BOM 的文件会把 `\ufeff` 送到摘要里）

## 效果（REPL 冒烟）

```

 2 ok  grep   2 处 :: notes.md:1 hello world
```
