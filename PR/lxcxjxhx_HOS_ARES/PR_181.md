## PR 描述

## 问题

`veripen_cli/offline.py` 的模块头写着“安装脚本里出现外网拉取即拒”。实测：

```
git clone 远端地址                    → 未命中
powershell -c "Invoke-WebRequest …"   → 未命中   ← 本产品 Windows 优先
scp user@host:/x .                   → 未命中
install.ps1 里的下载                  → 完全不扫（只扫 install.sh/uninstall.sh）
```

离线包的全部价值就在这句话上。两条路都走：把实现补齐，也把话改窄。

## 改法

- `EGRESS_PATTERNS` 补：`git clone`、PowerShell 下载原语
  （`Invoke-WebRequest` / `Invoke-RestMethod` / `iwr` / `irm` /
  `DownloadFile(` / `DownloadString(` / `Start-BitsTransfer`）、
  `scp|rsync` **到远端**（要求出现 `user@host:`，本地 `rsync -a` 不误伤）；
  `curl` 放宽到 IP 形式
- 扫描范围扩到 `install|uninstall` 的 `.sh` / `.ps1` / `.bat` / `.cmd`，并跳过注释行
  （`#` / `::` / `REM`）
- 模块头的口径改成：**常见形态清单，不是沙箱**——没命中不等于没有外网

## 效果

```
install.ps1            → install.ps1:1: PowerShell 下载原语 —— Invoke-WebRequest …
uninstall.bat          → uninstall.bat:1: curl 外网 —— curl …
git status             → 不误伤
rsync -a build/ dist/  → 不误伤
```
