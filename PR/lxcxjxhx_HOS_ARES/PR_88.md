## 期间修的四个真 bug

1. **`setup_stdout()` 只切 stdout，没切 stdin**
   管道进来的中文按 GBK 解码 →「写」变成乱码 → 只剩 ASCII 路径能认出来 →
   **每句话都被当成"读文件"**。加 `setup_stdio()`，并让 `_reconfigure`
   对 `io.StringIO` 兜底（否则测试必崩）。

2. **`sess.record` 遇孤立代理项直接抛**（`surrogates not allowed`）
   一条工具输出的乱码能把整个会话打崩。写库前 `_scrub()`。

3. **写意图只按"含'写'字"判断**
   「看下 x.txt 里写了什么」被判成 write。改成三条句式正则
   （往 X 写 Y / 写 Y 到 X / 创建 X 内容 Y）。

4. **Windows 下 `cmd -lc` 不存在**
   `执行 python -V` 永远 exit=1。执行器加 `cmd /c` 分支。

四个都不是笔误——第 1 个是"只修了一半输出通道"，第 2 个是"信任输入字节"，
第 3 个是"用关键词代替语义"，第 4 个是"POSIX 假设带到 Windows"。

## 关于模型
