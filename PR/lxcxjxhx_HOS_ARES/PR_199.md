## PR 描述

﻿## 两件事，都在 doctor 的口径上

**① 只验的项被判了死刑**

```
ok 17 / fail 0 / skip 3  →  不可交付
```

`skip` 不算 ok 是对的（没检查过的不算通过），但**没失败就说“不可交付”是过度声明**：一台没装 docker 的机器跑 `make doctor` 永远红，读者分不清“产品有问题”和“这台机器缺条件”。

**② 子进程输出按本地码页解**

`subprocess.run(..., text=True)` 在 Windows 上按 GBK 解码；子进程吐 UTF-8 时读线程直接崩：

```
UnicodeDecodeError: 'gbk' codec can't decode byte 0xae in position 20
pytest → PytestUnhandledThreadExceptionWarning → 用例整体 exit 1
```

## 改法

| 位置 | 改动 |
|---|---|
| `veripen_cli/cmd_doctor.py` | `verdict()` 三档：失败 / 未全绿（写明“不算通过，需在具备条件的环境复验”）/ 全绿；`--json` 带 `verdict` 与 `exit` |
| `veripen/doctor/__init__.py` | 同口径三档（这份枚举是 OK/WARN/FAIL → 告警档叫“可交付但有告警”） |
| `_run` / sandbox runner | 子进程统一 `encoding="utf-8", errors="replace"` |
