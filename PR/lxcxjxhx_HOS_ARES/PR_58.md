## 改了什么

- **设计令牌**收进 `:root`：颜色 / 间距 / 字号 / 圆角 / 焦点色 + 打印专用黑白令牌；
  深色是第二套令牌（`@media (prefers-color-scheme: dark)`），不是"顺手加几行"。
- 规则里**只允许 `var(--token)`**：`scripts/ui/contrast_check.py` 会拒绝令牌块之外的裸色值。
- **对比度闸门**：2 套配色 × 7 对令牌（fg/muted/weak/danger/accent × bg/surface），
  WCAG AA 4.5:1；`test_ui_contrast.py` 里还专门验"灰底灰字必须红"。
- **三态**：加载骨架 + `aria-busy`；空态 `role=status`；错误页 `role=alert`（`renderError`，
  文案明确写"这是环境或契约问题，不是「没有发现」"）。
- **密度两档**（舒适/紧凑）：切换 CSS 变量，偏好只存 `localStorage`，**不进任何请求**。
