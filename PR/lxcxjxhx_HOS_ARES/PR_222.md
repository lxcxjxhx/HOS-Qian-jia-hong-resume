## PR 描述

feat(console): 路由来源页对任何产物都是空表

## 判据

`ConsoleState` 有 `bindings` / `bounds` / `audit` / `approvals` 四个字段，
`web/loader.py` **一个都没填过**（grep 命中 0）。

其中 `ui.routes`（路由来源页）最要命——`hunt.json` 只记：

```json
"bindings": 12          ← 条数，不是内容
```

所以路由页对任何产物都是空表。想看一眼“本轮解析出哪些路由”，只能重跑一遍。

## 改法

| 位置 | 改动 |
|---|---|
| `cmd_hunt.py` | 产物加 `bindings_detail`：ref / 来源 / 置信度 / ttl / 模板指纹 / 标签，**上限 200 条**；**模板正文仍不落盘**（22 §2） |
| `loader.py` | 填 `state.bindings` + `bindings_total`（老产物的 `bindings` int 也读进来） |
| `console.py` | `ui.routes` 区分两种情形：有明细 → 出表；只有条数 → `detail_available:false` + note 说清“重跑一次 hunt 即可带上” |

## 实测

```
有明细产物 → bindings: 2 total: 2
             routes 页: {"total": 2, "detail_available": true, "note": ""} · 行数 2
老产物     → {"total": 7, "detail_available": false,
              "note": "本轮产物只记了绑定条数，没有逐条明细；重跑一次 veripen hunt 即可带上"}
```

老产物那条尤其重要：**空表不等于“没解析出路由”**，页面必须说出来。
