## 判据

`P=1.00 / R=0.93 / 闭环 1.00 / 硬门槛通过 / 越界 0` 这些数字全部来自 bench

## 改法

| 位置 | 改动 |
|---|---|
| `scripts/b12/run_bench.py` | 新增 `--limit N`：只跑前 N 例（冒烟用；子集跑**不是**验收数字） |
| `scripts/verify.py` | 新增一类闸门 `kind="smoke"`：`bench-smoke` = 3 例 × 1 轮，**不带 `--with-tests` 也跑** |
| `tests/unit/test_verify_script.py` | +2 条：冒烟必须显式带 `--limit/--rounds`；冒烟在快闸门里 |

关键点：子集跑**仍然走完整的硬门槛**（越界 / erro 率 / 闭环率 / routeset 一致），
