## PR 描述

﻿## 症状

顺着 B185/B186 查“档里配了但没人执行”的第三处，撞到更深的：

```python
plan=PlanDecision(allowed_oracles=oracles),   # build_guard 里直接造
```

`PlanDecision` 在构造时就把 `allowed` 填成了**待判列表**，于是 `preflight()` 里那句 `if not self.plan.is_allowed(oracle_id)` 永远为真——`scope.plan()`（它才实现 scope_in / deny / 影响顶棚 / 时间窗）**只在测试里出现过**。

实测（同一靶场）：

```
正常            → outcomes={reported: 2}
--deny <主机>   → outcomes={reported: 2}     ← 配了黑名单，照样发结论
```

## 改法

| 位置 | 改动 |
|---|---|
| `build_guard` / hunt 装配 | 改为 `scope.plan(...)` **真算**判定（scope_in / deny / 顶棚 / 窗） |
| `run` / `hunt` | 新增 `--deny`（逗号分隔主机）、`--max-impact`（默认 read_only） |
| `cmd_platform` | 档的 `scope.deny` 映射成主机传下去（资产 id → 主机；主机名原样） |
| `veripen_core/profile.py` | `policy.max_impact_class` 真正解析、校验并**进档哈希** |
