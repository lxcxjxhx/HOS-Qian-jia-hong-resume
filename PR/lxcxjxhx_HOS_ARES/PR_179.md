## PR 描述

## 问题

`Workbench.write` 的规矩是“默认不覆盖：覆盖不可逆，必须显式说”，`WriteResult` 也带着 `created`。

但 REPL 的 `_do_write` 一律 `overwrite=True`，摘要只写 `写入 N B`——
会话账本里“新建 a.txt”和“把 a.txt 换掉”长得一模一样。

数据其实一直都在（`created`），丢的是出口。

## 改法

- `WriteResult` 增加 `bytes_before`（覆盖前的字节数；新建为 `None`）
- `_do_write` 分两句写：
  - `a.txt 新建 5B`
  - `a.txt 覆盖 12B（原 5B）`

## 效果

```
write a.txt hello          → a.txt 新建 5B
write a.txt hello world!   → a.txt 覆盖 12B（原 5B）
```

REPL（真 stdin）两行同时出现；会话库与 `history` 记的是同一句。
