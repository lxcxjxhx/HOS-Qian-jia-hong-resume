## 设计要点

1. **租约不是锁**：锁要释放、会残留；租约自带过期，worker 崩了无需他人善后。
2. **时钟可注入**：不直接调 `time.time()`——时钟漂移是回收误判第一杀手。生产走 Redis `TIME`，测试走 `FrozenClock`。
3. **同资产串行**（分区键 = asset_id）：不同资产并行，同资产一次只跑一个任务。
4. **先证明不抢，再证明能接**：e2e 里在租约未过期时断言 `pick_next_respecting_partition` 返回 None，然后才等 TTL 过期接管。
