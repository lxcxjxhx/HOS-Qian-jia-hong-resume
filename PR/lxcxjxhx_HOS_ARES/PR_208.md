## PR 描述

fix(tests): 测试侧的子进程还在按 GBK 解，读线程一崩就报 NoneType.index

B190 只修了**产品代码**里的 `subprocess.run(text=True)`，测试侧漏了。

## 判据

```
pytest tests/integration/test_bench_leads_shared_target.py
→ 3 个 ERROR

堆栈里真正的错因：UnicodeDecodeError: 'gbk' codec can't decode byte 0xac
报给用户的：        AttributeError: 'NoneType' object has no attribute 'index'
```

读线程崩了 → `proc.stdout` 变 `None` → 报错信息离真因十万八千里。
