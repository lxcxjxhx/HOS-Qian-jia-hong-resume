## 形状

```
discovery/links.py       HTML → Sighting（纯函数，不联网）
discovery/templatize.py  具体路径 → 模板 + 参数名（三条规则）
discovery/crawl.py       绑定 → 观测记录 + 下一轮入口（fetcher 注入）
routes/sources           crawl 从空适配器换成真实现（provenance=CRAWL）
tools/http.py            send_body 与 send 共用同一条闸门链
veripen_cli/cmd_discover.py  veripen discover（不产判定）
```

**轮次模型**：抓链接要发请求，发请求必须持 `RouteBinding`，而绑定只能由 resolver 产出。
所以一轮只抓已绑定的面，新面交回 resolver 下一轮——地址纪律不破例。

**为什么 `send_body` 共享闸门**：读 HTML 也是一次出网；为拿 body 开"只读不审"的近路，
盲区正好落在最容易被绕过的发现阶段。
