## 唯一真缺口：CORS 预检

现状只覆盖"简单请求"：带 `Origin` 发 GET，看 ACAO 有没有反射。

缺的是**预检**：

```python
plan() → foreign_origin(Origin 头) / null_origin / same_origin(control)
# 三个变体都是 GET + Origin，没有 OPTIONS
```

预检配错的典型形态——允许任意方法/任意头 + 允许携带凭证——**比简单请求反射更危险**，而现在完全看不到。

修改计划写进 H31 了：加 `preflight` 变体 → judge 看 allow-methods/headers/credentials → bench 的 cors 案重跑确认判定变化是"更准"而不是"更松"。

**前置条件**：先确认 `GuardContext` 对 OPTIONS 的方法策略，否则真实目标上会被闸门拦成 BLOCKED。
