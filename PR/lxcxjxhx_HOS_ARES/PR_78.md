## 背景

`H13` 第二批。codex 面对应的是"能连着干几小时的活"——一期有 `Loop`/`Decider`/工作台工具，但 **TUI 是只读三面板**，没有"坐下下指令、看它干活"的入口。

## 做了什么

`veripen agent --db …`：一条指令一次动作，每步落 `task_events`，中断不丢、`--resume` 可恢复。

| 指令 | 动作 |
|---|---|
| `read <路径>` | 读工作根内的文件 |
| `write <路径> <内容>` | 新建/覆盖 |
| `edit <路径> <旧> => <新>` | 精确替换 |
| `sh <命令>` | 跑一条命令（五道闸生效） |
| `history` | 打印本次会话 |
| `quit` / EOF | 退出 |

**没有 delete**——`Workbench` 不提供的方法，这里也不提供（方法不存在即能力不存在）。

## 与 TUI 的分工

TUI（B56）是**只读三面板**，给"看"；会话是给"干"。
两者共用 `task_events` 作唯一真相源——会话不另存状态，恢复就是把事件读回来。
