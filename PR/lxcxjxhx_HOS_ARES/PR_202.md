## PR 描述

﻿## 判据

`web/console.py` 里那句注释是如实的——“内存里记最后状态（不落库、不碰发现）”。于是驭智面的审批入口是这样的：

* 客户点“批准” → 页面变成已批准 → **重启即失**；
* 审计页（读 `task_events`）里没有任何痕迹；
* 库里查不到“谁批的”。

一个看起来是审批的东西，实际只改了页面显示。

## 账本

H31 §2.3 新增（需裁决）：控制台的审批记录**还不参与执行侧判定**——控制台写 `task_events`，guard 的 `ApprovalGate` 读自己的 approvals 表。要让“控制台批准 = 动作放行”成真，需要两边对同一张表（与 B188 的写类审批门是同一件事）。

## 这条的教训

它最像“装饰性写入”：功能齐、按钮在、理由必填、自批被拒——唯独决定会消失。诚实的第一步不是打通执行，而是**先让它可查**，并在没接库时明说。

回滚：单提交 revert（回到内存记账；页面不再提落库）。
