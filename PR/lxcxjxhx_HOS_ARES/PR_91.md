## 背景

Codex / Claude Code 的日常是「改完顺便读一下」「跑完接着看报告」——B77 的 chat 每句话只产一个调用，不像在干活。

## 多步计划（不进 Loop）

```
> 把 a.txt 里的 x 改成 y 然后读一下
⏺ 计划  把 a.txt 里的「x」换成「y」 → 读 a.txt
  1. edit(path=a.txt, old=x, new=y)
  2. read(path=a.txt)          ← 第二段沿用第一段的路径
```

**为什么不改 Loop**：`tool_calls_per_step=1` 是 08 §2 写死的纪律（允许多个调用 = 允许它在一个 step 里越权串动作）。多步是用户显式要求的一串动作，由 `Plan.steps` 承载，逐步执行、每步仍是一次单一调用。

## 三处必须做对

1. **第二段沿用第一段路径**（"读一下"没带路径，靠分段历史）
2. **最后一步失败也要说**：`已停止：第 2 步失败（最后一步）` —— 不能因为"没有后续"就不吭声
3. **任一段解析不出就退回单步**，不做"一半执行一半猜"

另加 `/history`。
