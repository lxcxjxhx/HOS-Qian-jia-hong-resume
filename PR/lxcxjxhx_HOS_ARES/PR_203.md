﻿## 判据

给三处闸门（noroute / nodata / netimports）喂已知违规样本，问一句：**它到底能不能红？** 结果抓到一个真的。

```python
BANNED = re.compile(r"\b(mock|stub|fake|dummy)\b", re.IGNORECASE)
```

`\b...\b` 只匹配**独立整词**。而真实命名几乎都是复合形式：

```
class FakeTransport:      ← 不命中（"Fake" 后面紧跟 T，不是词边界）
def fake_runner():        ← 不命中
```

于是这条闸门**一次都没命中过**（全仓 0）。0 命中既可能是“代码干净”，也可能是“规则根本没匹配上”——后者更坏：它每轮都给你一个绿色的 0。

## 改法

| 目录 | 口径 |
|---|---|
| 产品代码（`veripen_core`/`veripen_oracles`/`veripen_contract`/`api`/`worker`/`web`） | 标识符里**出现即算**：`(?<![A-Za-z])(mock\|stub\|fake\|dummy)` |
| 测试代码 | 保留整词口径——`_fake_run` 这种测试替身名是正当的 |
