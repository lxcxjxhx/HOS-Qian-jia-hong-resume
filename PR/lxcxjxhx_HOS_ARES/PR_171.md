## PR 描述

## 问题

`cmd_platform` 的 `--openapi` 是 **required**；`run` 早就支持 `--discover`。

企业现场最常见的情况就是“没有契约”。于是 `veripen platform` 在这种环境下根本用不了——
多资产编排成了只有文档齐全的客户才能用的功能。

## 改法

- `--openapi` 与 `--discover` **二选一**：都给 → 退出 2；都不给 → 退出 2（不替你猜）
- 探测参数统一从 `_discover_args.add_discovery_args` 取，逐资产透传
  （`--discover-rounds / --discover-pages / --render / --submit-forms`）
- 报告写明**这批路由是契约给的还是探测来的**：探测面的证据强度弱于契约面，读者必须知道
