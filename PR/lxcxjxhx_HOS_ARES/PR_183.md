## PR 描述

## 问题

chat → platform 这条路上两处对不上：

**1. 「按档跑」永远卡在缺契约**

```
parse("用 demo-a 跑 openapi=…/spec.json")
  → platform{profile: demo-a}          ← 少了 openapi，执行层必然回“需要契约”
```

无模型时平台**必须**带契约（档只给资产与策略），规则层却给不出它自己要求的参数。

**2. 代签把签字人写成 operator**

chat 调 platform 时写死 `--approve`，平台把签字人一律记成 `operator`。
真正签字的是聊天里点 y 的人——审计栏变成编造。

## 改法

- `intent.py`：档意图补抓 `openapi=<路径>`（没写就照实不带，由执行层拒绝）
- `cmd_platform`：新增 `--approve-by`（默认 `operator`），写进审批事件与报告
- `cmd_chat`：代签时传 `--approve-by chat`

## 效果

```
parse("用 demo-a 跑 openapi=…") → platform{profile, openapi}
platform --approve --approve-by chat → 报告 | 审批 | 已签（chat） |
```
