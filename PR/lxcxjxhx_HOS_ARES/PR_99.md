## 取舍

`basePath` **折进路径**，而不是只放进 `servers`：我们的绑定层只给 host 补前缀
（`SymbolSource` + `--target`），路径前缀不会自动加回来——留在 `servers` 里，
整批请求会静默打到 404 上。

## 边界

- 只抄 strix `utils/api_spec.py` 的 `classify` / `base_urls` 两个判据；
  operations 仍走我们 `veripen_contract/parser.py`（纯函数 / 不出地址 / 零猜）。
- 契约包不许 import 网络栈（AST 闸门），所以不用 `urllib.parse`，字符串切分。
- `formData` 明确不做（宁缺不猜）。
