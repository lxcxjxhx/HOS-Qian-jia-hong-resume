## 问题

`hunt` 对 VERIFIED 的结果返回：

```json
{"verdict": "VERIFIED", "capsule_id": "sha256:sqli_bool_diff"}
```

那不是哈希，是 `f"sha256:{oracle_id}"` 拼出来的字符串。`hunt` 根本不写 capsule，
`out/capsules/` 下没有这份文件。而且它经过

```
veripen_core/tools/registry.py:303  →  ToolResult.data
```

进了**模型上下文**。报告读者会照着指针去核对；模型不会——它会把 `sha256:csp_absent`
当成证据写进结论。同一形状还有两处：`scripts/demo.py`、`scripts/b26/agent_live.py`。

前几轮修的都是"给人看的出口"，这一批是"给模型看的出口"。同一个谎换个收件人，
杀伤更大：人会核对，模型不会。

## 改法

三处统一 `capsule_id: None` + `evidence: "not_sealed"`（demo 是 `pending_seal`），
hunt 另给一句 `evidence_note`：

```
hunt 不封 capsule：这条结论没有可重放证据；要证据请用 veripen run
```

没有顺手"封个 capsule"：hunt 的落盘与链要单独设计（已登记账本 `open`）。
这一批只把**假指针**拿掉——少说一句比说错一句好。
