## PR 描述

> 基于 #238（E1 真隔离）。那一条讲「怎么把容器跑起来」，这一条讲「怎么让每个任务各跑一个」。

## 这一批解决什么

E5 的另一半。进程内并发早就有（三任务指纹与串行一致），缺的一直是**任务之间看不见彼此**。

## 改了什么

| 文件 | 改动 |
|---|---|
| `hos_ares_core/parallel.py` | 新增 `ContainerTask` / `ContainerRun` / `run_parallel_containers` |
| `hos_ares_cli/cmd_parity.py` | E5 探针验两半：进程内指纹 + **容器级并发与串行逐条相同** |
| `tests/integration/test_parallel_containers.py` | 新增 8 项 |

判据与进程内版**同形**：并发结果必须与串行逐条相同 —— 不是"看起来对"。

三条纪律照旧：

- 上限 `D-H-05` 的 3，超了直接抛 `ParallelError`，**不排队**（悄悄串行会让调用方以为在并行）；
- 没有容器档执行体 → `blocked`，**不降级到进程内**（那是把没隔离伪装成隔离了）；
- 结果按 `task_id` 排序，顺序与调度交错无关。
