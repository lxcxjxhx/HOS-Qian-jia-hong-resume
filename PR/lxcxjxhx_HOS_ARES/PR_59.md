## 这次实测撞出并修掉的三个真实故障

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 页面停在「加载中」，导航空白 | 浏览器缓存了**旧 `router.js`**（新页面 import 了新符号，模块还是旧的） | 静态响应加 `Cache-Control: no-cache`；模块 URL 用 `router.js?v=1` 显式版本化 |
| 2 | 启动期异常只写 console | 用户只看到「加载中」，无法自救 | `window.onerror` → 渲染错误页（`role=alert`） |
| 3 | 点「跳到主内容」直接回 overview | `#main` 被 hash 路由当成换页 | `router.js` 增 `isRouteHash`：非 `#/` 开头的 hash 不触发渲染 |

第 3 条正是 B42 判据 C 想抓的东西——如果只写静态检查而不真正按一次 Tab，这个 bug 不会出现。
