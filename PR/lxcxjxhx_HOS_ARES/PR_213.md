四处写着 16：

| 文件 | 行 |

| `docs/delivery/dist-checklist.md` | `- [ ] make doctor 16 项全绿` |
| `packaging/offline/README.txt` | `python -m veripen_cli.cmd_doctor  # 16 项自检` |
| `packaging/offline/install.sh` | 安装完成提示里的 `# 16 项自检` |

客户读到的数字必须是真数字，否则“自检 20 项”这句话本身就没被自检。

## 改法

四处改成 20，并加一条用例把**交付材料里的项数**与 `CHECKS` 长度绑死：

```python
_DOC_PATHS = ("README.md docs/delivery/quickref.md … packaging/offline/install.sh").split()
_DOC_COUNT = re.compile(r"(\d+)\s*项(?:自检|全绿)")
assert checked, "交付材料里没有任何项数说法——这条检查会永远绿，得先补样本"
```

第 6 行 `assert checked` 是故意的：一条“没扫到样本也算过”的检查等于没有。
