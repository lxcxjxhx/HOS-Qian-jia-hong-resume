## 问题

B152 把 `hunt` 里的假证据指针（`sha256:<oracle_id>`）拿掉了，但拿掉之后它只是“没有”：

```
hunt（lab 脆弱态，openapi 两条面，scripted 模型）
  确认：2 条
  证据：0 份 capsule        ← strix 那条“边跑边打”的路，结论没有一份可重放证据
```

## 改法

- `HuntRuntime` 接 `capsules_dir`：VERIFIED 且 judgement/pairs 齐全时
  `build_capsule` → **用上一条的 self 作 prev 增量封印** → `save_capsule`
- 工具结果返回**终值** id（`evidence="sealed"`）——不需要 B148/B150 那种“封印后回填”
- 造不出来记 `evidence="build_failed:<kind>"`，仍不给假 id、也不留半份文件
- hunt 复用同一 `--out` 改为拒跑（exit 2），与 B153 的 run 同一条规矩
- `hunt.json` 增加 `capsules`（本轮自哈希）与 `capsule_ids`（oracle → id）

## 为什么是增量封印

B148（面覆盖面）和 B150（封印后 id 变了）都是同一种窗口：**先算出一个 id，后来才发现得改**。
hunt 这里把 prev 一条条接上去，id 在返回给模型之前就定稿——没有回填，也就没有指错的机会。
