## 改法

**控制台真跑一次**（`tests/integration/test_console_browser.py`）：

- 起真 uvicorn（空闲端口）→ 项目自带 `BrowserRenderer` 打开 `/ui/app` → 再切到 `#/findings`
- 断言：`outcome ok`、写出用的浏览器通道、`paths` 里出现 `/ui/overview`、`/ui/findings`
  （只有 JS 真取数才会有），以及发现页 DOM 里出现载荷里的 `asset-b181`
- 驱动放在**独立解释器**里（`_console_browser_driver.py`）：uvicorn 会在自己线程里建
  事件循环，而 Playwright 同步 API 不许在“当前线程已有循环”时用——同进程跑会
  被别的用例留下的循环绊倒（实测：单跑绿、整跑红）

**README 三个数字**改真，并绑成用例（`tests/unit/test_cli_usage.py` 增 3 条）。
