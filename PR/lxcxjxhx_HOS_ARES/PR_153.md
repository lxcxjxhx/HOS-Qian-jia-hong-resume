## 怎么发现的

把同一轮运行的四份输出**并排比数**：

```
coverage:  {reported: 7, no_issue_found: 2, blocked: 1, undetermined: 2}
报告四态:  {reported: 7, undetermined: 3, error: 0, not_run: 2}
```

`no_issue_found`（跑过判否）在报告里落进了 `not_run`，而这一行的表头写着
**「未执行（授权/预算/跳过）」**。

这正是本项目文档明令禁止的混淆——**"跑过判否"被读成"没跑"**。

## 改法

不动四态规格（09 §4 是已发布口径，改状态要走决策），而是**把这一格拆开说明**：

- `FindingView.refuted: bool`（附加字段）
- `not_run` 行同时给出"真正未执行 N 条"与"另 M 条为已判否"

读者一眼能分清"我们没测"和"我们测了、没问题"。
