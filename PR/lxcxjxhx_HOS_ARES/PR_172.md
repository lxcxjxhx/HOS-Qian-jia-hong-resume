## 问题

`run` 有 `--token`，`platform` 没有透传。同一个资产：

```
veripen run      --token …   → auth 相关 oracle 能跑
veripen platform            → 只能落 BLOCKED，而且报告不说为什么
```

## 改法

- `--token` 逐资产透传给 `cmd_run`
- 报告写凭据状态，**不落原文**（报告是要发给客户的）：
  `- 凭据：主身份 token 已注入（不落原文）` / `- 凭据：未提供——auth 相关 oracle 会落 BLOCKED`
