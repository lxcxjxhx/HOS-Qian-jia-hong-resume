## 三个问题，一个根因

`hunt.json` 有两个来源：

```
findings   = {"csp_absent": "VERIFIED"}                              ← 只有 verdict
faces_run  = [{oracle_id, route_ref, template, verdict, reason}]      ← 逐面权威
```

loader 读了前者：

| 症状 | 后果 |
|---|---|
| `finding_id = F-001…` 按序号 | 顺序一变 id 就变；同一 oracle 多面时**撞 id** |
| `capsule_id = sha256:<oracle>` | **编造证据指针**——hunt 不封 capsule |
| `route_ref = None` | 丢掉产物里明明有的真实面 |

第二条最严重：控制台给出一条指向不存在 capsule 的「证据」，与它自己文档里
「空输入安全 · 不塞假数据」直接冲突。
