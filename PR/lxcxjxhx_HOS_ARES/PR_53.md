## 本批判据（`H07` B36 / `H08` A15 页面契约同构）

九页 payload 必须 ⊇ 对应 view 函数的键集；**少一个键就是漂移**，前端会在没人看控制台的日子里读到 `undefined`。

## 修的是什么（三处真实漂移）

| 页 | 现状 | 修法 |
|---|---|---|
| `ui.coverage` | 返回 `{"confirmed":1,"unconfirmed":2}` —— 规格要的是矩阵 | `coverage_from_findings()` 从 findings 派生矩阵，`scope=observed_only` 自报分母；扁平计数**不再被接受** |
| `ui.finding` | 无视 `id`，永远第一条 | `?id=` 取数三态 `query / fallback / default`，`requested` 显式回显（回落不许冒充命中） |
| `ui.audit` | 恒空，读起来像"没有留痕" | 返回 `events / count / source`，`source ∈ {state, unavailable}`；**"没有事件源"和"没有留痕"必须能区分** |

附带：`ui.unverified` 增 `by_verdict` 兼容视图（三组旧契约一字未动）；`ui.overview` 增
`unverified` 与 `coverage{tested, blocked, total, zero_hit_tags}`，**"已测"只算 verified，blocked 单列**
（把阻塞算成"已测"就是 D1 的另一种违反）。
