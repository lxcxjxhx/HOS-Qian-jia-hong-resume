## 问题

`OracleMeta` 只声明 `severity_rule`（规则名，如 `server_side_fetch`），**没有等级**。
报告层于是落到默认 `medium`——SSRF 和"限流缺失"在客户报告里是同一档。

## 做法

`veripen_oracles/policy.py` 增 `SEVERITY_BY_RULE` + `severity_for()`：

- 规则 → 等级，再套 `cap_severity`（限流类上限 `low`）；
- **表是产品政策，不是测量结果**：单个 oracle 不许各自写数字，否则谁都能往高里写，
  改表走 review；
- 表外规则兜底 `medium`，但 `basis=default` 写进 `situation`——否则 `medium` 会被读成"评估过"；
- 弱面（`crawl`/`probe`）high/critical 仍压到 `medium`，`basis=weak_face_cap`。

映射依据是语义（可被第三方复现的数据外泄/越权/注入 = high；需交互或配置缺失 = medium/low），
不是从历史数据拟合出来的——这一点写进了注释，避免下一个人以为是统计结果。
