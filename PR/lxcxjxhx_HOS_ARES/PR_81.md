## 踩的坑

**卡片 PNG 与 mp4 混进同一个 concat 会花屏。**

`-loop 1` 必须配 `-framerate`，且 `-t` 要放在 `-i` **之后**（输出时长）——
放在输入前会被解释成"读输入多久"，单图输入直接报错退出（exit 4294967294）。

所以流程是：卡片 → 各自转成同参数 mp4（1280×720/30fps/yuv420p）→ 与素材一起进 concat。
