## 五条硬门槛

| 门槛 | 违反后果 |
|---|---|
| FP > 0 | 硬失败 |
| 越界（post_connect）> 0 | **整轮作废** |
| error 率 > 2% | 该轮作废（「没测成」≠「结果不理想」） |
| 三轮 `routeset_sha256` 不一致 | 停线（resolver 有隐藏非确定性） |
| 同 case 三轮 verdict 不一致 | 停线（judge 不纯 = 架构 bug） |

额外一条运行时验证：**渲染结果必须能由该轮 RouteSet 推出**。
比对用的是「绑定模板 + 参数重算」，不是「实际访问的 path」——
后者含服务器重写/尾斜杠噪声，会把运行时验证退化成「网络栈是否忠实回显」。
