## 问题

`ui.finding` 给的复现命令是：

```
make replay ID=F-csp_absent-38dcb568
```

而 `make replay` 的 `ID=` 是 **capsule 文件路径**（`--capsule "$(ID)"`）。
照抄 → `capsule 载入失败`。

同一类病第三次出现：

| 批次 | 位置 | 形态 |
|---|---|---|
| B149 | report.md | 文件名拼错（`sha256:<hex>.json`） |
| B151 | report.md | 默认 `--mode live`，CLI 缺件即拒 |
| **B157** | 控制台 | `ID=` 里放的是 finding_id，不是文件路径 |

三次都不是算错，是**命令长得像命令**，却没人真的跑过它。

## 改法

- `web/loader.py` 装载时解析每行证据文件的真实路径（`capsules/**/<sha>.json`，
  内容寻址——只查找、不推断；找不到就是 `None`）
- `web/console.py`：`repro` = `veripen replay --capsule <真实路径> --mode offline`；
  盘上没有文件时 `repro=""`、`repro_ok=false`，不给假命令
- `web/static/index.html`：证据段直接显示这条命令（原来写“（下载未接线）”）
- 页面契约同步：`capsule_path` / `repro_ok`

## 效果（真实产物）

```
out/b118-e2e  F-csp_absent-38dcb568
  capsule_path = out/b118-e2e/capsules/d767b0c1….json
  repro = veripen replay --capsule out/b118-e2e/capsules/d767b0c1….json --mode offline
  repro_ok = true；load_capsule(该路径).capsule_id 与行内一致

指针在、文件不在 → repro = ""、repro_ok = false（不假装能复现）
```
