## PR 描述

feat(offline): 离线包说“不需预装任何软件”，包里却没有 Python 和依赖

## 判据

`packaging/offline/README.txt` 原文：

> 除 docker（>= 24）外，不需预装任何软件

然后三步安装的第三步是 `python -m veripen_cli.cmd_doctor`——可包里**没有 Python**，
也**没有运行期依赖的 wheel**。干净内网主机跑到第三步就 `ModuleNotFoundError`。

承诺写得比现实好，是这一族里最难被自己发现的一种：**没人会在断网机器上读第二遍**。

## 改法（能力补上 + 话改准）

| 位置 | 改动 |
|---|---|
| `veripen_cli/offline.py` | `build(wheels_from=DIR)` 把 `*.whl` 与 `requirements.lock` 带进 `wheels/`；**给了目录却没有 whl → `PackageError`**（不产出假目录）；`verify()` 把空 `wheels/` 如实报为问题 |
| `scripts/package_offline.py` | 新增 `--wheels-from` |
| `packaging/offline/install.sh` | 新增「2/5 安装运行期依赖」：`pip install --no-index --find-links wheels -r wheels/requirements.lock` |
| 外网闸门 | `pip install` → **不带 `--no-index` 的 `pip install`**（离线装是正当的） |
| `packaging/offline/README.txt` | 预装要求改成实话：docker + Python 3.11+，依赖随包 |
