## PR 描述

﻿## 判据（一次真实 run 的 report.md）

```
- 复现（离线重判）：`veripen replay --capsule C:/Users/<操作员>/AppData/Local/Temp/.../capsules/<sha>.json`
```

报告是要发出去的东西：绝对路径把操作员的目录结构写进交付物，换台机器就读不出来。而 `findings.json` 里**根本没有**证据路径字段——机器消费者只能自己猜 `<out>/capsules/<self_sha256>.json` 这个命名约定。

## 改法

| 位置 | 改动 |
|---|---|
| `cmd_run` | `capsule_dir` 改传 `capsules`（相对 `--out`） |
| `render_json` | `evidence.capsule_path = capsules/<self_sha256>.json` |
| `render_markdown` | 行首写清“在报告所在目录执行” |

## 账本

## 这条的性质

不是算错，是**交付形态**问题：同一份证据，报告给绝对路径、JSON 不给路径、控制台自己拼第三个。三处都能用，但只有一种能发出去。

回滚：单提交 revert（回到绝对路径 + JSON 无路径字段）。
