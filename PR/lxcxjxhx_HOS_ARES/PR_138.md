## 以前那句“没有 docker 就 SKIP”吞掉了什么

| 能验的 | 探针 |
|---|---|
| 超时真的会杀 | `sleep 30` + `timeout=2` → 必须 `blocked` |
| 退出码不被吞 | `exit 3` → 回来还是 3 |
| 输出被捕获 | 打一行 → stdout 里必须有 |

这三件不需要容器。现在拆成两条检查：**行为可验 → OK**；**隔离未验 → SKIP**。

## 最关键的一条是否证

`attest()` 里 `isolation` 只信执行体自报，`job-object` 不许写成 `container`；
非容器隔离时 `verdict()` **直接返回 False**。把资源隔离说成真隔离，比“没验过”更糟——
所以这里给出的是“**它现在不是容器隔离**”这个否证。
