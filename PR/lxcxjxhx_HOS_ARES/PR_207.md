## workflow 的口径：构建即自检

```
1) 打单文件
2) 起服务 → GET /ui/app → 断言 200 + <title> + id="nav"
3) 打安装包
4) 静默装一遍 → 跑装出来的 exe → 断言页面 → 静默卸载 → 断言无残留
5) 上传 artifact；推 tag 时两个产物都附到 Release
```

打得出 ≠ 装得上，装得上 ≠ 打得开——所以第 4 步是真的装一遍再开一次，失败就不上传。
