## 修的是什么

实测（B30 真实数据）时 `/ui/findings` 里：

```json
{"id":"F-003","severity":"high","confidence":0.0,"priority":11.0,"queue":"now","hits":0}
```

而 `/ui/unverified` 里它写着 `BLOCKED: baseline_abnormal`。
一条**没测成**的条目以"高危 / 立即看"排在唯一真结论（medium / 8.0）前面 —— 判定域 D1（缺输入 ≠ 没漏洞）在展示层被违反。
