## 三个坑（都进了代码注释）

1. **精简 env 让 socket 初始化失败**（`WinError 10106`）
   subprocess 只传 `PATH`/`PYTHONPATH` 时，Windows 缺 `SystemRoot` 等变量 → Winsock 起不来 →
   靶场连不上 → 所有 oracle 报 OSError。修：`dict(os.environ)` 复制再覆盖。

2. **管道下默认 locale 编码（GBK）**
   `PYTHONIOENCODING` 不够，中文解成乱码，判据里的关键行永远匹配不上。修：加 `PYTHONUTF8=1`。

3. **命令串在 `scene.prompt` 不在 stdout**
   去掉重复的 `$ …` 行后，判据 B 一度假红。修：把 `scenes[].prompt` 纳入校验 blob。
