## PR 描述

fix(console): 详情页的“三条 trace 摘要”永远显示“未提供”

## 判据

发现详情页有这么一段：

```
③ 三条 trace 摘要
   未提供（trace 未注入）        ← 每一个发现都是这句
```

而它的**数据源早就在旁边**：

| 环节 | 状态 |
|---|---|
| `ConsoleState.traces` 字段 | 有 |
| `ui.finding` 返回 `traces` | 有 |
| 前端表格渲染 | 有 |
| **`web/loader.py` 填它** | **没有** |

`grep -c trace web/loader.py` = 0。而 ④ 段展示的证据包里，`steps` 正是 baseline /
probe / control 三步。

## 改法

`load_traces(capsule_path)`：从 capsule 的 `steps` 只读映射出 `{role, status, bytes}`；
装载时按行填进 `state.traces`。坏 JSON / 空路径 / 文件不存在 → 返回空
（页面照旧说“未提供”，**不编数据**）。

## 实测（真产物）

```

        {'role':'probe','status':200,'bytes':59}]
```

control 是 403——这正是“反证请求被拒”的那一步，以前它在页面上根本不存在。
