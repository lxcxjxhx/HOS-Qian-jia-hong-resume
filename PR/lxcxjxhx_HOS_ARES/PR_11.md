## Summary

Rootfs build infrastructure for reproducible pre-installed APK builds.

## Changes (+977, 5 new files)

**scripts/Dockerfile.rootfs:**
- Multi-stage Alpine-based rootfs builder
- Pre-installs all Python wheels and system deps
- Outputs optimized rootfs.tar.gz with marker file
- Non-root build, cache layer optimized

**scripts/build_full_rootfs.py:**
- Master orchestrator: install system + pip + create marker
- Idempotent, with lock file and verification
- Reads dependency list from \equirements/\

**scripts/build_rootfs.sh / .ps1:**
- Cross-platform entry points for local development
- Support incremental wheel only rebuild
- Output rootfs.tar.gz ready for assets/

**scripts/download_wheels.py:**
- Download pre-built wheels for offline installation
- Platform-tag aware (py3-none-any, manylinux)
- Skips already-downloaded wheels

## Impact

- Enables reproducible, deterministic rootfs builds
- Zero-network APK: all deps baked into rootfs
- CI-ready: scripts can run in GitHub Actions
