## PR 描述

## 问题

`run` 一直有 `report.md`；`hunt` 只有 `hunt.json` + 终端输出。

交付物不对称：客户拿到 hunt 结果，要自己读 JSON 才知道
“确认了什么、为什么没确认、覆盖到哪、证据在哪”。

## 改法

- 新增 `veripen/report/hunt.py`：`render_hunt_markdown(record, …)`
- `cmd_hunt` 写完 `hunt.json` 后用**同一个 record dict** 渲染 `hunt.md`
  （同源是关键：报告里的每个数都来自 hunt.json，不另算一遍）
- 报告结构（口径照抄 report.md）：
  1. 结论：只列 VERIFIED，逐行指证据；未确认单独一张表且**必须带原因**；再附按 oracle 的粗视图
  2. 覆盖：面/缺口/完整性；`完整：否` 时说明“以 X 结束（reason）”，不让人误以为还有面没跑
  3. 证据：链长、链头、每份的 `veripen replay --capsule <真实路径> --mode offline`
  4. 模型自述（标注**不计入判定**）
  5. 附录：offline 只重判不重发；REFUTED / BLOCKED / INCONCLUSIVE 不是一回事
