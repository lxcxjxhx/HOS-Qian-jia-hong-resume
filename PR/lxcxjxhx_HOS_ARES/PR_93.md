## PR 描述

## 背景

现在要 `python -m veripen_cli.cmd_chat` / `cmd_run` / `cmd_platform`… 记不住九个模块名。Codex 是 `codex`，Claude Code 是 `claude`。

## 做了什么

```
$ veripen --help            # 或 python -m veripen_cli
子命令：chat run platform hunt console agent tui doctor parity playbook replay

$ veripen chat --help       # 透传给 cmd_chat
$ veripen doctor --only python
$ veripen nosuch            → exit 2 + 列出可用
```

## 三条设计

1. **原样透传**：中间层不解析、不改写、不补默认值 —— 一旦帮补参数，`--help` 与实际行为就分叉
2. **不引 click/typer**：零依赖纪律（离线包要能装进内网），argparse 够用
3. **直调路径不变**：`python -m veripen_cli.cmd_*` 照旧，不破坏既有脚本

## 顺手修的一处

`--version` 原来返回 `0.0.0`（`veripen_cli/__init__.py` 没有 `__version__`）。补上，并让测试锁住它与 `pyproject.toml` 一致——两处各写一份版本号迟早会分叉。
