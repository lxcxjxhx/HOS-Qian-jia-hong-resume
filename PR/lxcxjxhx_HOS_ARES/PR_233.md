而它装的是：镜像 tar + Linux wheel，入口是 `sh install.sh`。**我们同时发 Windows 的
exe 与安装包**——Windows 断网主机拿到这个包，跑 `sh install.sh` 会在中途才报一句看不懂的错，

## 改法

| 位置 | 改动 |
|---|---|
| `README.txt` | 新增第〇节「哪个平台用这个包」：面向 Linux（x86_64/arm64）；**Windows 走 `HOS-ARES-Setup-<ver>.exe`**；Mac 只作开发验证 |
| `install.sh` | 平台闸门：`uname -s` 不是 Linux/Darwin → 直接 `exit 2`，并指出 Windows 的路径 |

```sh
case "$(uname -s 2>/dev/null || echo unknown)" in
    Linux|Darwin) : ;;
    *) echo "本包面向 Linux（x86_64）；当前平台 … 请改用安装包："
       echo "  Windows：HOS-ARES-Setup-<ver>.exe（静默安装见 docs/exe-quickstart.txt）"
       exit 2 ;;
esac
```
