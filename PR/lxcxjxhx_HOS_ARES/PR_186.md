## 背景

继续用“这条检查有没有可能失败”扫 parity 剩余项：

| 项 | 旧探针 | 问题 |
|---|---|---|
| P3 压缩 | `tokens_after > 0` | 压不动也会绿 |
| G3 断言表 | 正文里出现字符串 `A20` | 连“A20 还没做”都能骗过 |

把 P3 改成真比前后，**当场红了**：

```
压缩没有变小：3 -> 7
```

3 token 进、7 token 出——摘要的表头开销压过了节省。那不叫压缩。

## 改法

- `compress()`：`after >= before` 时**原样返回**并标 `mode="passthrough"`
  （新增第三值；已 grep 确认仓内没有按 mode 分支的消费方）
- P3 拆两段：小输入**不许放大**（必须 passthrough），真实规模**必须真变小**
- G3 改成数表里的行：A1–A20 是否齐全，缺了列名字
