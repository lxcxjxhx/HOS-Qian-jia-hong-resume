## PR 描述

feat(agent): sh 是唯一能跳出工作台的出口，而它没有任何闸门

## 判据

```
read / write / edit / glob / grep  → 受 Workbench 根约束
sh                                → 跑什么就是什么，用的是当前账号权限
```

`chat` 与 `agent` 两个入口都**没有任何危险命令判断**（grep 命中 0）。

企业侧最容易被问倒的一条就是：“你的 agent 会不会把 `rm -rf /` 执行了？”

实测（改前）：

```
> 执行 rm -rf /
⏺ sh(cmd=rm -rf /)
  ✓ exit=0        ← 真跑了
```

## 改法

新增 `veripen_core/workbench/danger.py`：19 条规则，每条带名字与理由。

| 类 | 例子 |
|---|---|
| 整盘/整目录删 | `rm -rf /`、`rm -rf ~`、`del /f /s /q C:\*`、`rd /s` |
| 分区/磁盘/引导 | `mkfs`、`dd of=/dev/…`、`fdisk`、`shutdown/reboot` |
| 系统配置 | `reg delete`、`iptables -F`、`chmod 777 /`、`crontab -r` |
| 凭据面 | `/etc/shadow`、`SAM`、`NTDS.dit`、`.aws/credentials` |
| 远程直跑 | `curl … \| sh`、`iwr … \| iex`、`powershell -enc`、`base64 -d \| sh`、fork 炸弹 |

两个入口默认拦，拒绝**记成一步（ok=False）**；放行只有一种方式：显式 `--allow-dangerous`。
