## PR 描述

## 背景

用户不提供 docker，要求自行想办法。本机实测：docker / podman / nerdctl 都没有，WSL 未安装，Docker Desktop 要管理员权限 + 重启——**装不上**。

但"没有容器"不等于"只能裸跑 subprocess"。Windows 有 Job Object。

## 做了什么

`select_executor()` 变三级：`docker → job-object → None`（调用方翻 BLOCKED）。

| 保证 | 不保证 |
|---|---|
| 进程数上限（防 fork 炸弹） | 文件系统隔离 |
| 内存上限（防 OOM 拖垮宿主） | 网络隔离 |
| 句柄关闭即整组杀（无残留） | 权限降级 |
| 超时强杀（`TerminateJobObject`） | 内核隔离 |

**它不是容器**，所以 `isolation` 如实写 `job-object`：

```
✅ 沙箱执行体 —— job-object（isolation: job-object —— 资源隔离，非容器；E1 真隔离仍未验）
```

## 两处修正（都会静默出错）

1. `AssignProcessToJobObject` 要 `SET_QUOTA|TERMINATE`，我最初写成 `SET_INFORMATION|QUERY_INFORMATION` —— **权限不对会静默失败**：进程照跑，但完全不受限，看起来一切正常
2. 拿不到句柄时如实报 `assign_failed`，不假装受限——没进 job 就不是受限执行
