## PR 描述

fix(run): 抓不到页面时，报的是次要原因

## 判据

第一次上手最常见的错——端口没开：

```
$ veripen run --target http://127.0.0.1:1 --discover --out out/x

发现第 1 轮：抓 3 页 / 新面 0 条
没有可跑的 oracle —— 逐面原因：
  - http://127.0.0.1:1：这条面没有语义标签（响应形状推不出类型、也没有参数）
```

**真实原因是连不上**，但程序报的是"没有语义标签"。读者会去改标签，白费时间。
**指向错比不说更费时间。**

## 改法

抓取全失败时如实报原因并指出是哪一层：

```
这一轮一页都没抓成：fetch_failed×3
连接层面就没过——先确认目标可达（端口/证书/代理）再谈覆盖面：
可试：curl -sS -o NUL -w '%{http_code}' http://127.0.0.1:1
```

## 一个自己踩的坑

第一版提示用的是 `host`（只是主机名），实测印成 `127.0.0.1`——**丢了端口**，
那条命令指到默认端口上，等于没提示。改用用户原样给的 `target`。
