## 这不是算错

两个集合：`summary` 数**全部**缺口，caveat 只数**阻断性**的（critical+warn）。

但同一份文档里 `5` 和 `3` 并排放着，读者会以为有一处算错——**账本最怕这种“看起来对不上”**。

修法是让两个数同时出现并说明关系，而不是把其中一个改掉。改掉任何一个都会丢信息：只留 5 会夸大问题，只留 3 会掩盖有 5 条缺口。

## 这个缺陷是怎么发现的

```

```

两个数在同一个响应里，肉眼一对比就不对。**跑一遍真东西比读十遍代码有用。**
