## 改法

新增 [impact.py](veripen/report/impact.py)，只用**已声明的元数据**（oracle 的
`ImpactClass` + 判定出的 severity）生成人话：

| 写入等级 | 影响 |
|---|---|
| `read_only` | 只读取证：目标数据未被改动；被读出的内容本身即信息泄露，影响面按 CWE 归类。 |
| `reversible_write` | 写入可逆：证据里保留了改动前后的值，可按证据回滚。 |
| 未知 | 影响面未声明：该 oracle 没有给出写入等级，需人工判定。 |

建议按严重度给三条，**都指向同一个可验证动作**：修复后重跑本 oracle，判定应变为 REFUTED。

`cmd_run` 与 `scripts/demo.py` 两条出口共用同一套；demo 的占位符删掉。
