## 三条为什么不能一把梭

同一个骨架 `_HeaderAbsent`，但**“有保护”的判据必须各自想清楚**：

| oracle | 判据 | 用错的后果 |
|---|---|---|
| CSP | 头存在且非空 | 只看头存在 → 空值被当成"有保护" |
| 点击劫持 | XFO **或** CSP `frame-ancestors` | 只看 XFO → 现代站点全被判缺失（假阳性） |
| nosniff | 值 == `nosniff` | 只看头存在 → `none` 被当成"有保护"（假阴性） |

两侧都可能错，所以每条都单独写了 `_present()` 覆盖。
