## PR 描述

test(installer): “装完点开就是界面”只有一次运行证明，没有用例守着

## 判据

用户当初那句需求——装完从开始菜单/桌面点开就是 HOS-ARES 的界面——目前只由 CI 跑过一次
（`build-exe` 的「自检安装包」步骤：装 → 开 → 断言 200 → 卸 → 断言无残留）。

但**没有任何用例守着那份脚本还在说这句话**。改一行 `Flags` 就可能变成不弹窗、不建快捷方式，
而测试全绿。

## 改法

新增 `test_installer_contract`（4 条静态契约）：

```
开始菜单入口指向 {app}\HOS-ARES.exe
桌面图标跟 desktopicon 任务走（企业环境常常不需要桌面图标）
收尾页 postinstall + skipifsilent（静默安装不弹窗，否则批量部署被卡住）
卸载只删 {app}，不动用户产物（out/ 不在安装目录下）
```

并把「静默安装不会自动打开界面」写进 `docs/exe-quickstart.txt`：
企业批量部署时这是**预期行为**，但以前没写，容易被当成 bug 报上来。
