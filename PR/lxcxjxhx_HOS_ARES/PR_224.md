## 判据

B214 的闸门能拦住 `rm -rf /`，但两个缺口让它只做了一半：

**① 计划里看不出危险**

```
⏺ 计划  执行命令：rm -rf /
  1. sh(cmd=rm -rf /)  — 执行命令        ← 和 echo hi 长得一样
```

“计划先于执行”给的否决权其实用不上——人看不到该否决什么。

**② 放行不留痕**

`--allow-dangerous` 跑完后，步骤摘要与普通命令一模一样。**拒绝有记录、放行没记录**，
审计时看不出谁按了那个开关。

## 改法

- `_render_plan`：对 `sh` 步骤先算命中，打一行 `⚠ [name] 理由`
- `_exec_step`：**始终**算一遍命中（不是 `None if allow_dangerous else …`），
  被放行时摘要前加 `[DANGER-OVERRIDE name]`

## 实测

```
⏺ 计划  执行命令：rm -rf /
  1. sh(cmd=rm -rf /)  — 执行命令
     ⚠ [rm-root] 删根/家目录/通配：不可逆，且删的不只是工作根
⏺ sh(cmd=rm -rf /)
  [GATE-DANGER] rm-root：… （确实要跑就加 --allow-dangerous）

带 override 跑 mkfs.ext4 /dev/null →
  ⏺ sh(cmd=mkfs.ext4 /dev/null)
    [DANGER-OVERRIDE mkfs] ✗ exit=1
```
