## 为什么这么判（先查证再改）

HTTP 上 `application/pdf`、`image/*`、`font/*` 是**文件**不是**页面**
（[MDN Common types](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/MIME_types/Common_types)）。
拿 oracle 打它们只会得到一份二进制响应，然后把覆盖率分母撑大——
`face_without_oracle` 会把它们全算成缺口，账本立刻被噪声淹没。

## 边界

- `.jsp` / `.php` / `.aspx` **保留**：服务端页面，响应是 HTML。
- `/export?file=x.pdf` **保留**：path 无后缀，它确实是页面端点。
