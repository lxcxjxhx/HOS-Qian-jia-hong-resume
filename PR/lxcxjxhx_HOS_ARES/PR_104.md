## 问题

B81 把 chat 接到了模型，但复用的是**判定链路**的系统提示（"只选 oracle"）。
模型于是永远答 `run_oracle`，被 `CHAT_TOOLS` 白名单拒掉，每轮静默降级 `rules`——
"接通了但没接管"。假模型服务永远回预设 tool，测试看不出来。

## 修法

- `HttpChatClient` 支持 `system_prompt`；给了就跳过 agent 的 few-shot
  （那套示例教的是 oracle 选择，留着会继续把模型带偏）；
- chat 自带 `CHAT_SYSTEM_PROMPT`，工具表与 `_exec_step` 读的字段名**逐字一致**
  （`sh{cmd}` / `read{path}` / `run{target,openapi}` …）；
- 假模型服务记录首条 system 消息，测试断言它含 `sh{cmd}` 且不含 `run_oracle`。
