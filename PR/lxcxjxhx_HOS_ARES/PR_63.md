## 本批判据（`H07` B47）

## 修的是什么

之前是两套清单：

```
agent 的 7 个工具（registry.py，模型看得见）
workbench 的 fs/shell（另一套，模型看不见、不受预算与审计约束）
```

合并后：**名称唯一、schema 唯一、impact 唯一、审计唯一**。

| 层 | 内容 |
|---|---|
| `ToolSurface` | 12 个工具：7 agent + `fs.read/write/edit` + `shell.run` + `browser.render` |
| 注册 | 同名二次注册 → `SurfaceError(duplicate_tool)`，启动即失败 |
| 准入 | `read` 自由 / `write` 记账 / `exec` 必须 `approved=True`（否则 `approval_required`） |
| 审计 | 每次调用进 `audit()`：tool / impact / allowed_by / result |
| 派生 | `ALLOWED_TOOLS` 与 `tool_schemas()` 都从 surface 来（清单唯一来源） |
| 未接线 | 返回 `blocked/not_configured`——"没接线"和"执行失败"是两件事 |
