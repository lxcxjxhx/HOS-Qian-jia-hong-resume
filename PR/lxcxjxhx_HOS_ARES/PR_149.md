## 改了什么

老账 B12：`cors_misconfig` 只判"简单请求"——带 `Origin` 发 GET 看 ACAO 反射。
缺的是**预检**：`OPTIONS` + `Access-Control-Request-Method`。

预检配错（允许任意方法/头 + 允许携带凭证）比简单请求反射更危险，之前完全看不到。

| 层 | 改动 |
|---|---|
| `Variant` | 新增 `method`（空 = 用 binding 的方法） |
| `run()` | 透传；**只有非空才传**，不强迫每个传输实现 |
| `CoreTransport` | 按 method 覆盖请求行，地址不变 |
| `RenderTransport` | 非 GET 显式 `method_unsupported`，不假装发过 |
| `CorsMisconfig` | `preflight` 变体 + judge 看 allow-methods/headers/credentials |

## 一个必须记下的坑

第一版把预检设成 **probe**，bench 召回从 0.929 **掉到 0.857**：

```
lab 不支持 OPTIONS → 405 → three_way_holds 判 false → 整条判定降级 INCONCLUSIVE
```

预检本质是"顺带看一眼"，改用 `readback` 角色（`three_way` 只看 probe/control）后恢复。

**没有 B134 那道门槛，这个改动会静默弱化两条正例**——这是我这两轮里最值钱的一次自证。
