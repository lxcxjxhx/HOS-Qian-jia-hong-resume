## ⚠️ 本批修掉三个真缺陷（都会让证据系统看起来能用其实不安全）

### 1. `verify_integrity()` 拿现算值和现算值比 —— 防篡改形同虚设
```python
# 错：to_dict()[chain][self_sha256] 本身就是现算的，恒等
claimed = self.to_dict()[chain][self_sha256]
# 对：保留文件自称值，与现算值比对
if self.claimed_self_sha256 != actual: raise CAPSULE_TAMPERED
```

### 2. `capsule_from_dict` 丢弃 `created_at`
合法 capsule round-trip 后 `created_at` 变 0，序列化写成现在，哈希必变 → **任何合法 capsule 一读回就自我报篡改**。改为 `_parse_rfc3339` 还原。

### 3. `to_payload()` 直接返回 `assertion` 引用
调用方能透过返回值改 capsule 内部状态，`frozen dataclass` 的不可变性被穿透。改为 `copy.deepcopy`。

### 附带：`Step` 增加 `raw_body_sha256` / `raw_body_len`
读回的 body 已截断到 4KB，从截断后内容重算哈希会与原始不符——会踩第 2 类同一个坑。
