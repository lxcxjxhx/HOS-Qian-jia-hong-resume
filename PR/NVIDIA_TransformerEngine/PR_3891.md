# Description

Restructure only — no code change. The body now follows this repository's template so
the checklist can be answered rather than implied; the technical content is unchanged
from what was already reviewed and approved.

Fixes the `-inf` handling of the online-softmax merge in the cross-entropy kernels: a
shard that is entirely masked makes `global_m == -inf`, and `exp(m - global_m)` then
computes `exp(-inf - -inf)`, which is `nan`, poisoning the loss and every gradient
through it.

## Changes

- add `_softmax_shift(maximum)`: returns `0.0` when the running maximum is `-inf`, the
  maximum otherwise
- use it in `cross_entropy_forward_kernel`, `cross_entropy_tp_pre_kernel` and
  `cross_entropy_tp_post_kernel` in place of the raw maximum, so a fully masked block
  contributes zero mass instead of `nan`
- `tests/pytorch/test_cross_entropy.py::test_parallel_cross_entropy_leading_neg_inf_block`:
  a 32k-vocabulary row whose first 32 760 logits are `-inf`
- `tests/pytorch/distributed/test_parallel_cross_entropy.py::test_parallel_cross_entropy_tensor_parallel_leading_neg_inf`:
  three ranks where two hold entirely masked shards, compared against single-rank
  `torch.nn.functional.cross_entropy`
