## What

Two docstrings in `transformer_engine/pytorch/permutation.py` name the third parameter `sorted_indices`, but both signatures take `sorted_index` (singular). Numpydoc renders the parameter list as the contract, so an IDE hover or the Sphinx API page shows a name that cannot be passed as a keyword:

```python
moe_sort_chunks_by_index(inp, split_sizes, sorted_indices=idx)   # TypeError: unexpected keyword
moe_sort_chunks_by_index(inp, split_sizes, sorted_index=idx)     # works
```

Same for `moe_sort_chunks_by_index_with_probs`. Two lines, doc-only:

```diff
-    sorted_indices : torch.Tensor
+    sorted_index : torch.Tensor
```

## How this was found

An AST pass over `transformer_engine/` (520 Python files) comparing each numpydoc parameter name against the enclosing signature. Before: 9 stale names repo-wide, including these two. After: 7, and the two remaining in this file are gone.
