## 为什么不直接放 `<video>`

这张卡是通过 `<a><img src="profile-anim.svg"></a>` 加载的。**SVG 作为图片载入时不会请求任何外部资源**——远程 mp4、png、字体全部拿不到，脚本也不执行。内嵌 data URI 动图（GIF / 动画 WebP）和 SMIL 是唯一能活下来的两种运动途径。

提交前已实测：内嵌动画 WebP 在 `img → svg → image` 这条链路下逐帧播放（同一文件两次不同时间点采样，画面不同）。
