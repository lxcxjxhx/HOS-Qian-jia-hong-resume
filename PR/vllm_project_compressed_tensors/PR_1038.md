## PR 描述

### What changed

Ten text-mode JSON opens under `src/` used the platform default encoding, so a Hugging Face `config.json` containing any non-ASCII value failed on a machine whose default codec is not UTF-8:

```
UnicodeDecodeError: 'gbk' codec can't decode byte 0xad in position 76: illegal multibyte sequence
```

| file | reads | writes |
|---|---|---|
| `utils/moe.py` | `load_model_config` | — |
| `utils/mtp.py` | config | config |
| `utils/safetensors_load.py` | config, index | config |
| `compressors/model_compressors/model_compressor.py` | config | config |
| `entrypoints/convert/convert_file.py` | config | config |

All now name UTF-8.

### Why it is reachable

`load_model_config` and `get_quantization_config` both read the model's `config.json`, which is the publisher's text: `_name_or_path`, `architectures`, and free-text fields routinely carry non-ASCII. The save path is the mirror image — it dumps with `json.dump(..., ensure_ascii=False)` and then opens the target without an encoding, so it declares Unicode output and writes it in the local codepage.

### Reproduction (before / after)

```python
# config.json written with encoding="utf-8"
# {"architectures": ["QwenForCausalLM"], "_name_or_path": "中文模型名称", ...}

load_model_config({"w": "config.json"})
get_quantization_config("config.json")
```

```
before: UnicodeDecodeError: 'gbk' codec can't decode byte 0xad in position 76   (both)
after:  both return the parsed dict
```

### Scope

- ASCII configs are unaffected: UTF-8 and the local codepage agree on every byte an ASCII config contains.
- Deliberately not touched: `tests/` (~53 sites), `examples/`, `utils/copyright.py`, the `"rb"` opens, `safe_open(...)` safetensors handles, and the `/proc` reads. The first three are not library paths; the rest are not text.
- Not touched either: `model_compressor.py`'s `json.dump` already writes with `ensure_ascii` defaults; only the `open` needed an encoding.

### Checks run

- Both functions above, run against the checkout and against the patched modules loaded from disk (red/green in the same session).
- Not run: pytest, because this checkout needs a GPU-capable torch and `tmp_path`; the config paths above touch neither.
