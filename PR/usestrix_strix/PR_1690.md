## What

`strix/skills/tooling/agent_browser.md` contains four markdown links to `references/*.md`:

```
[references/authentication.md](references/authentication.md)      (twice)
[references/video-recording.md](references/video-recording.md)
[references/session-management.md](references/session-management.md)
```

There is no `references/` directory anywhere in this repository. Those files ship **inside the `agent-browser` CLI** — the same document says so at the end:

> `agent-browser skills get core --full`
> That pulls in:
> - `references/commands.md` — every command, flag, alias
> - `references/authentication.md` — auth vault, credential handling
> …

so a relative link here resolves to a path that will never exist in the checkout, and renders as a dead link in the skill pack the pentest agents load.
